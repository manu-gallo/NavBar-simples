# Sistema de Cadastro de Alunos

Este é um projeto simples desenvolvido em HTML com o objetivo de simular um sistema de cadastro de alunos.

O site possui várias páginas interligadas com informações sobre cursos e um formulário de cadastro.



## Funcionalidades

- Página inicial do site
- Página sobre a instituição
- Página de cursos disponíveis
- Páginas individuais para cada curso:
  - Informática
  - Enfermagem
  - Marketing Digital
  - Gastronomia
  - Contabilidade
- Formulário de cadastro com:
  - Nome completo
  - E-mail
  - Idade
  - Curso
  - Turno
  - Interesses
- Página de confirmação de cadastro
- Página de contato
- Navegação entre páginas
- Botão de voltar ao início



## Tecnologias utilizadas

- HTML



## Estrutura do projeto

- index.html → Página principal
- inicio.html → Página inicial do site
- sobre.html → Informações sobre a instituição
- cursos.html → Lista de cursos
- informatica.html → Página do curso de Informática
- enfermagem.html → Página do curso de Enfermagem
- marketing-digital.html → Página do curso de Marketing Digital
- gastronomia.html → Página do curso de Gastronomia
- contabilidade.html → Página do curso de Contabilidade
- cadastro.html → Formulário de cadastro
- sucesso.html → Confirmação do cadastro
- contato.html → Página de contato
- administracao.html → Página adicional de curso
- img/ → Pasta com imagens utilizadas no site
- README.md → Descrição do projeto


## Como usar

1. Abra o arquivo index.html ou inicio.html no navegador
2. Navegue pelas páginas do site
3. Acesse a página de cadastro
4. Preencha o formulário
5. Clique em enviar




## Objetivo

Este projeto foi desenvolvido para praticar a criação de páginas em HTML, uso de formulários e navegação entre páginas.
